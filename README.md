# LifeTime-Mod

This Minecraft mod adds two highly configurable in-game timers:

World Timer: Tracks the total in-game time of a world or server
Session Timer: Tracks the current play session since joining

Both timers are fully customizable, allowing players to adjust:

Display colors
Screen position
Time units (seconds, minutes, hours, days)
Formatting and display options

The mod works in both singleplayer worlds and multiplayer servers, helping players keep better track of their gameplay time.
